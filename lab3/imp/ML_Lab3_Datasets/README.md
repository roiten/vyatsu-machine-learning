# Локальные наборы данных к лабораторной работе № 3

В каталоге находятся 30 CSV-файлов индивидуальных вариантов, двухмерный
набор `example_moons.csv` для сквозного примера классификации и набор
`example_regression.csv` для краткого примера метрической и SVM-регрессии.

Наборы индивидуальных вариантов совпадают с лабораторными работами № 1 и № 2.
Это позволяет сопоставить kNN и SVM с ранее исследованными линейными моделями
и многослойной нейронной сетью при одном экспериментальном протоколе.

## Использование

1. Поместите каталог `ML_Lab3_Datasets` рядом с Jupyter Notebook.
2. Найдите свой вариант в `manifest.csv`.
3. Загрузите файл из столбца `file_name`.
4. Имя целевого признака возьмите из столбца `target_column`.

Все CSV-файлы содержат исходные признаки и целевой столбец. Индекс Pandas в
файлы не записывался. Пропущенные значения сохранены в стандартном CSV-виде.

Комплект вариантов: 30 файлов.
Учебный пример классификации: `example_moons.csv`, 600 объектов, 2 признака.
Учебный пример регрессии: `example_regression.csv`, 320 объектов, 1 признак.

## Происхождение и контроль целостности

Наборы вариантов получены из OpenML по идентификаторам `data_id`. Учебные
наборы созданы детерминированно с фиксированным seed. Для каждого варианта и
для `example_moons.csv` в `manifest.csv` приведена контрольная сумма SHA-256.
