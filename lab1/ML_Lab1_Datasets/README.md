# Локальные наборы данных к лабораторной работе № 1

В каталоге находятся 30 CSV-файлов индивидуальных вариантов и отдельная
локальная копия Titanic для сквозного учебного примера.

## Использование

1. Поместите каталог `ML_Lab1_Datasets` рядом с Jupyter Notebook.
2. Найдите свой вариант в `manifest.csv`.
3. Загрузите файл из столбца `file_name`.
4. Имя целевого признака возьмите из столбца `target_column`.

Все CSV-файлы содержат исходные признаки и целевой столбец. Индекс Pandas в
файлы не записывался. Пропущенные значения сохранены в стандартном CSV-виде.

Комплект вариантов: 30 файлов.
Учебный пример: `example_titanic_40945.csv`, OpenML data_id 40945.

## Происхождение и контроль целостности

Данные загружены из OpenML по идентификаторам `data_id`. Для каждого файла в
`manifest.csv` указаны исходная страница, заявленная лицензия и SHA-256.
Использование наборов данных должно соответствовать условиям, указанным на
странице соответствующего набора OpenML.
