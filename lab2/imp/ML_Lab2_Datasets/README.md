# Локальные наборы данных к лабораторной работе № 2

В каталоге находятся 30 CSV-файлов индивидуальных вариантов и отдельная
локальная копия набора `digits` для сквозного учебного примера.

Наборы вариантов намеренно совпадают с лабораторной работой № 1. Это позволяет
сравнить многослойную нейронную сеть с ранее исследованными линейными моделями
на одних и тех же данных и при сопоставимом экспериментальном протоколе.

## Использование

1. Поместите каталог `ML_Lab2_Datasets` рядом с Jupyter Notebook.
2. Найдите свой вариант в `manifest.csv`.
3. Загрузите файл из столбца `file_name`.
4. Имя целевого признака возьмите из столбца `target_column`.

Все CSV-файлы содержат исходные признаки и целевой столбец. Индекс Pandas в
файлы не записывался. Пропущенные значения сохранены в стандартном CSV-виде.

Комплект вариантов: 30 файлов.
Учебный пример: `example_digits.csv`, 1797 объектов, 64 признака, 10 классов.

## Происхождение и контроль целостности

Наборы вариантов получены из OpenML по идентификаторам `data_id`. Набор
`digits` входит в scikit-learn. Для каждого CSV-файла в `manifest.csv` указаны
источник и контрольная сумма SHA-256.
